# Extract Audio

**Версия:** 0.2.0-beta.1 · **Build 1**  
**Автор:** Andrii Semenenko

Настольное приложение на Python/Tkinter для извлечения аудио из локальных видео и доступных ссылок YouTube/Vimeo.

## Возможности
- Извлечение аудио из локальных видео.
- Загрузка доступных аудиопотоков по ссылкам YouTube/Vimeo.
- MP3 с битрейтом 32, 48, 64, 96, 128 или 192 кбит/с.
- Выбор временного фрагмента.
- Прогресс, журнал, ошибки и отмена.
- Встроенные окна «Справка» и «О программе».

## Запуск
```bash
python3 -m pip install -U yt-dlp certifi
python3 main.py
```
Убедись, что FFmpeg доступен через `PATH` или `~/bin/ffmpeg`. `HELP.md` должен лежать рядом с `main.py`.

## Сборка
```bash
python3 -m pip install -U pyinstaller yt-dlp certifi
python3 -m PyInstaller --clean ExtractAudio.spec
```
Проверь путь к FFmpeg в `.spec` перед сборкой. В `datas` должен быть включён `HELP.md`.

Загрузка по ссылкам зависит от доступности видео и текущей поддержки сайта в yt-dlp. Используй только материалы, к которым у тебя есть разрешённый доступ.
