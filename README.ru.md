# Extract Audio

**Версия:** 0.2.0-beta.1 · **Build:** 1\
**Автор:** Andrii Semenenko

Extract Audio --- настольное приложение на Python/Tkinter для извлечения
аудио из локальных видео и доступных ссылок YouTube/Vimeo.

## Возможности

-   Извлечение аудио из локальных видео.
-   Загрузка доступных аудиопотоков по ссылкам YouTube/Vimeo.
-   Сохранение в MP3 с битрейтом 32, 48, 64, 96, 128 или 192 кбит/с.
-   Выбор временного фрагмента.
-   Отображение прогресса и журнала, сообщения об ошибках и отмена
    операции.
-   Встроенные окна «Справка» и «О программе».

## Структура файлов

Для macOS поддерживаются отдельные файлы запуска и конфигурации сборки
для двух архитектур:

  -----------------------------------------------------------------------------------
  Архитектура             Файл приложения          Файл сборки PyInstaller
  ----------------------- ------------------------ ----------------------------------
  Intel (`x86_64`)        `main_macos_x86_64.py`   `ExtractAudio_macos_x86_64.spec`

  Apple Silicon (`arm64`, `main_macos_arm64.py`    `ExtractAudio_macos_arm64.spec`
  например M1/M2/M3/M4)                            
  -----------------------------------------------------------------------------------

Собирай приложение на Mac с соответствующей архитектурой и с нативным
Python этой архитектуры. Для проверки архитектуры Python выполни:

``` bash
python3 -c "import platform; print(platform.machine())"
```

Ожидаемый результат: `x86_64` для Intel или `arm64` для Apple Silicon.

## Запуск из исходников

Установи зависимости Python:

``` bash
python3 -m pip install -U yt-dlp certifi
```

Убедись, что FFmpeg доступен через `PATH` или находится по пути
`~/bin/ffmpeg`. Затем запусти соответствующий файл, например:

``` bash
python3 main_macos_arm64.py
```

Файл `HELP.md` должен находиться в корне проекта рядом с исходными
файлами.

## Сборка приложения для macOS

Установи PyInstaller и зависимости:

``` bash
python3 -m pip install -U pyinstaller yt-dlp certifi
```

### Apple Silicon (arm64)

На Mac с Apple Silicon из корневой папки проекта выполни:

``` bash
python3 -m PyInstaller --clean ExtractAudio_macos_arm64.spec
```

Результат:

``` text
dist/Extract Audio.app
```

### Intel (x86_64)

На Intel Mac из корневой папки проекта выполни:

``` bash
python3 -m PyInstaller --clean ExtractAudio_macos_x86_64.spec
```

Результат обычно находится в `dist/`. Используй именно имя приложения,
заданное в соответствующем `.spec`.

Перед сборкой проверь в нужном `.spec`: - путь к FFmpeg; - путь к
исходному файлу Python; - наличие `ExtractAudio.icns` и `HELP.md`; -
включение FFmpeg и `certifi` в конфигурацию сборки.

После сборки запусти приложение и проверь извлечение MP3. Успешная
сборка сама по себе не подтверждает совместимость на всех версиях macOS
и других компьютерах.

## Создание DMG с ярлыком «Программы»

Следующие команды приведены для Apple Silicon и предполагают, что
приложение собрано в `dist/Extract Audio.app`. Выполняй их из корневой
папки проекта.

Создай папку содержимого образа, скопируй приложение и добавь ссылку на
папку Applications:

``` bash
mkdir -p release/dmg
rm -rf "release/dmg/Extract Audio.app"
cp -R "dist/Extract Audio.app" "release/dmg/"
ln -s /Applications "release/dmg/Applications"
```

Создай DMG:

``` bash
hdiutil create \
  -volname "Extract Audio" \
  -srcfolder "release/dmg" \
  -ov \
  -format UDZO \
  "release/ExtractAudio_0.2.0-beta.1_macOS_AppleSilicon.dmg"
```

Проверь образ:

``` bash
hdiutil verify "release/ExtractAudio_0.2.0-beta.1_macOS_AppleSilicon.dmg"
```

Открыв DMG в Finder, пользователь сможет перетащить `Extract Audio.app`
на ярлык `Applications`.

Для Intel-сборки используй соответствующее приложение из `dist/` и
измени имя выходного DMG, чтобы в нём было явно указано `Intel` или
`x86_64`.

## Подпись и предупреждения macOS

Текущая бесплатная сборка может быть неподписанной и не
нотарифицированной Apple. При запуске на другом Mac macOS может показать
предупреждение о разработчике. Это следует учитывать при передаче
приложения другим пользователям.

## Важные замечания

-   Для работы приложения требуется FFmpeg. При распространении
    необходимо проверить, что его библиотеки включены и корректно
    загружаются на компьютере, где Homebrew не установлен.
-   Загрузка по ссылкам зависит от доступности видео и текущей поддержки
    сайта в `yt-dlp`.
-   Используй только материалы, к которым у тебя есть разрешённый
    доступ.
